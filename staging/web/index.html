Microphone and staging help

On Android, open this HTTPS URL in Chrome, sign in using the same ChatGPT account, then tap Speak. If asked, allow microphone access. If you denied it, open Chrome’s site permissions and allow the microphone, then retry.

Check microphone briefly opens the microphone and immediately stops its audio tracks. Speech recognition is provided by the browser and may send audio to its speech provider. Momentum stores text only; audio is not recorded or uploaded by this app.

Use the text box if speech is unsupported, blocked, offline or interrupted. Review the transcript before saving. No production Momentum tasks or Google Sheets are connected. Staging notes persist until the isolated staging database is removed; no automatic retention policy is enabled.

Limits: 1,000 tasks and 2,000 notes per staging account; last 500 approved structure changes shown in audit.
